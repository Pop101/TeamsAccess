# TeamsAccess

A Python prototype that reads calendar entries from the Microsoft Teams web interface using Selenium.

## Table of Contents

- [Scope](#scope)
- [Technologies](#technologies)

## Scope

This is not an official Teams integration. It depends on browser markup that may change and has not been verified against the current web app. Use only with accounts and calendar data you are authorized to access; for supported integrations, start with [Microsoft Graph's calendar API](https://learn.microsoft.com/en-us/graph/api/resources/calendar).

- [Python](https://www.python.org/)
- [Selenium WebDriver](https://www.selenium.dev/documentation/webdriver/)
